# 票务助手 · 我的购票计划

把想看的演出收进列表，排好场次和票档的先后顺序，设置预算，在开售时收到提醒。

**当前版本：0.2.0。新增完整的购票计划界面，但仍不能在真实大麦自动下单、锁票。**“自动抢票”按钮明确显示为待接通；界面内的自动购票演练只使用虚构库存，不产生真实订单。

## 这一版具体补了什么？

| 功能 | 实际能做什么 |
|---|---|
| 演出列表 | 自动收集浏览器中已加载的大麦搜索/详情页公开信息，按演出 ID 去重 |
| 未开售筛选 | 把明确有未来开售时间、待开售但时间不明、状态不明和过期信息分开 |
| 搜索与排序 | 搜索演出/城市，按最近开售或最近采集排序 |
| 购票计划 | 选择演出，填写具体场次/票档、调整优先级，保存张数和含费用预算 |
| 倒计时与提醒 | 统一按北京时间处理开售时间，到点发系统通知，点击通知打开官方演出页 |
| 完整流程演练 | 用你填的备选顺序演练首选售罄、成功、验证码、超时和超预算 |
| 原有文字观察 | 仍可在大麦网页观察指定文字出现 |

**“自动收集”指读取你已打开、已加载的官方页面，不是自动遍历全站，也不是服务器余票查询。**现在没有可靠的全站“最近未开售场次”数据源。页面没加载出数据时，界面会为空，不会补上虚构的真实演出。

目前采集的是演出项目，项目内的具体场次和票档仍需对照官方页面填写。缺少年份、没有时分或没明确写“开售/开票”的时间不会被猜成开售时间，演出日期也不会拿来代替开售日期。

## 从 GitHub 下载后怎么打开？

1. 点击仓库绿色 **Code → Download ZIP**，然后解压。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`，开启开发者模式。
3. 点击“加载已解压的扩展程序”，选择解压项目里的 **extension 文件夹**。
4. 点击浏览器工具栏里的扩展图标，再点 **打开购票计划界面**。

从 0.1 更新：替换原文件后在扩展管理页面点“重新加载”。这一版新增了官方页面读取、本地存储、定时器和系统通知权限，浏览器可能会要求你确认。扩展只在声明的大麦搜索/演出详情页自动采集，不读取 Cookie、密码、观演人表单或订单页面。

## 怎么把演出放进界面？

在界面点击“打开大麦搜索”，像平时一样搜索演出。等列表正常加载后，扩展会自动收集已加载的演出链接、名称和可识别开售时间；页面继续加载时也会更新。可以打开感兴趣的演出详情页补充信息。

回到界面，可以点“采集已打开页面”重新采集当前页面，再用“明确尚未开售”筛选。若没有结果，先看看官方网页是否正常显示内容；这不等于最近没有演出。

每条信息保留采集时间，超过24小时标为过期。列表最多保留200个项目，不会自动翻页，也不保证覆盖全站。页面采集规则尚未在正常加载的大麦演出列表上验收，页面结构不同可能采不到。

想先看看样子，可以点击“用虚构演出看看界面”。虚构数据明确标注、与真实列表隔离，也不能保存成真实提醒。

## 怎么设置自己的备选？

选中一场演出，在右侧/下方的计划区核对开售时间。时间输入全部按**北京时间**解释，不受电脑所在时区影响。

按顺序填写，例如：

1. 周六19:30，680元票档。
2. 周六19:30，480元票档。
3. 周日19:30，680元票档。

点击箭头可以上移优先级，再填写张数与最高总价。保存后，它会出现在“我的提醒”，到点提醒你去官方页面。目前这套计划不会自动选票或下单。系统通知需要浏览器运行，电脑休眠或通知权限关闭可能导致延迟或不显示；界面也会显示提醒状态。

## 自动抢票目前还差什么？

还缺真实大麦的场次/票档识别、结算信息核对、一次性提交订单，以及可靠的待付款订单确认。无法读取这些真实页面时，不能只凭“立即购买”几个字就点击下单。

2026-09-12 核实时，大麦公开搜索页在远程浏览器中持续显示“努力加载中”，没有可用演出列表。这次没有拿到真实结算流程，也没有提交任何真实订单。没有证据说明这是机器人拦截，不把加载失败当成平台禁止或允许自动化的结论。

下一步需要具体演出页面或正常加载页面的验证，核实渠道和平台规则后再接下单功能。不能保证抢到票；验证码、排队和本人校验也不会被绕过。

## 为什么要先停下来查单？

页面超时不一定代表没买到：服务器可能已经创建了订单，只是页面没有返回。程序的核心规则是：**明确售罄且没有形成订单，才试备选；提交结果不明，先暂停核对。**这些规则已在核心测试与模拟代码里实现，但真实订单查询还没有接通。

## 本地预览与开发

完整界面不需要 Python，安装扩展就能打开。只想预览界面时，在项目根目录运行：

```sh
python -m http.server 8765 --bind 127.0.0.1
```

打开 [界面预览](http://127.0.0.1:8765/extension/ui/dashboard.html)，可查看界面并演练；官方采集和系统提醒仅在扩展中可用。旧演示仍在 [旧模拟页面](http://127.0.0.1:8765/demo/)。

Node.js 20 或以上可运行核心测试，无需安装依赖：

```sh
npm test
```

旧演示的浏览器检查脚本需要额外安装 Playwright 与 Chromium：

```sh
npm install --no-save playwright
npx playwright install chromium
node tests/browser.cjs
```

| 位置 | 内容 |
|---|---|
| `extension/ui/` | 演出列表、购票计划、提醒与流程演练界面 |
| `extension/catalog.js` | 链接、开售时间、列表与计划校验 |
| `extension/collector.js` | 官方页面公开信息采集 |
| `extension/background.js` | 本地存储、串行写入、系统提醒 |
| `extension/engine.js` | 购票判断核心 |
| `tests/` | 决策、解析和后台测试 |
